# Changelog

## [1.0.1] - 2026-09-28

- Organize package documentation, preserve API and migration examples, and add Stackline community links.
- Improve package discovery keywords with precise domain terms and `stackline`.
- Pin GitHub Actions release tooling and require an explicit missing-version response before publication.


## 1.0.0 - 2026-08-27

- Preserve callback and synchronous `find-parent-dir@0.3.1` behavior.
- Propagate non-missing filesystem errors instead of silently crossing them.
- Add an additive Promise API.
- Add native ESM and first-party TypeScript declarations.
- Preserve historical `index` and `index.js` deep imports.
- Add regression, differential, permission, symlink, platform, type, package,
  registry, documentation, and release verification.
- Keep the runtime dependency graph empty.
